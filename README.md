# Java Calculator

## Description
A simple Java calculator that allows users to perform basic arithmetic operations using two numbers entered through the console.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Invalid operation handling

## Technologies
- Java
- Scanner class for user input

## How to Run
1. Open the project in your Java IDE.
2. Run the `Calculator.java` file.
3. Enter two numbers when prompted.
4. Choose an operation from the menu (1–4).
5. View the result in the console.
